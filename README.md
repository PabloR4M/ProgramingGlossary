# ProgramingGlossary

## Descripción
Esta es una aplicación iOS desarrollada como actividad de examen ordinario para el laboratorio de iOS Development. En esta aplicación se explican diversos conceptos de programación, aplicando directamente los conocimientos y habilidades adquiridos durante las sesiones del laboratorio.

## Requisitos
Para poder abrir y compilar este proyecto, necesitas:
* Una computadora Mac con macOS.
* **Xcode** instalado (se recomienda utilizar una versión reciente).
* Un simulador de iOS o un dispositivo físico configurado para desarrollo.

## Cómo ejecutar el proyecto
1. Descarga o clona este repositorio en tu computadora local.
2. Abre la carpeta del proyecto y haz doble clic en el archivo `Glosario.xcodeproj`.
3. Una vez que el proyecto cargue en Xcode, selecciona un simulador (por ejemplo, iPhone 14 o iPhone 15) desde la barra superior.
4. Haz clic en el botón de **Play** (o presiona las teclas `Cmd + R`) para compilar y ejecutar la aplicación.

## Herramientas y Tecnologías Usadas
* **Plataforma:** iOS
* **Lenguaje:** Swift
* **Entorno de Desarrollo (IDE):** Xcode
